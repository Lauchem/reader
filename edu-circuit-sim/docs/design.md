# 设计说明（可复制到 Word）

## 1. 作品概述

作品名称：电路仿真实验课件（Windows桌面版，绿色便携）

面向对象：小学高年级/初中物理入门

教学内容：欧姆定律、串联电路、并联电路、电压与电流测量

目标：通过可交互的“实验台”让学生观察参数变化与测量结果，形成“变量—结果”的因果认知；同时提供练习评价与学习数据记录。

## 2. 功能设计

### 2.1 仿真实验模块

- 连接方式：串联 / 并联切换
- 实验台插槽：支持 1–3 个电阻元件（拖拽放置、可移除、可清空）
- 电源电压：1–12V 滑块调节
- 自动计算与显示
  - 等效电阻 Rt
  - 总电流 It
  - 各电阻的电压与电流（串联：分压；并联：分流）
- 实验记录：一键保存本次实验（参数+计算结果）

### 2.2 实验记录模块

- 列表展示：最近实验记录与练习成绩
- 导出：导出为 JSON 文件（便于备份与提交材料打包）
- 清除：清除全部本地记录（用于“卸载/重置”）

### 2.3 练习评价模块

- 随机生成 5 题选择题（欧姆定律、串并联规律、仪表连接方法）
- 自动判分（每题 20 分）
- 显示解析与正确答案
- 保存成绩记录（时间、得分、答题详情）

### 2.4 使用说明模块

提供可直接用于提交材料的文字说明：运行步骤、操作步骤、卸载方式、模型假设与注意事项。

## 3. 教学设计要点

- 以“调参—观察—对比”为核心流程：电压变化/电阻组合变化 → 立即反馈（表格与仪表）
- 典型实验情境
  - 串联：固定电压，改变电阻组合，观察电流变化与分压规律
  - 并联：固定电压，改变支路电阻，观察各支路电流与总电流
- 形成性评价：练习题即时反馈与解析，辅助巩固概念

## 4. 技术实现

- 桌面端：Electron（Windows）
- 安全策略：关闭 NodeIntegration，启用 ContextIsolation，通过预加载脚本提供最小化 API
- 数据存储：本机 JSON（用户目录），支持导出与清除
- 打包：electron-packager 生成 Windows 绿色目录，可压缩为 ZIP

## 5. 运行环境与安装卸载

- 运行环境：Windows 10/11 x64
- 安装：绿色版无需安装，解压后双击运行
- 卸载：删除解压文件夹；如需删除个人数据，在软件内“实验记录”→“清除全部记录”
